# My Sky Island 
Дипломный проект 2024 года.<br>
Создание креативной видеоигры на основе концепции Minecraft Sky Block.<br>
Версия игрового движка - 2022.3.25f1 LTS

# Управление
- WASD - Ходьба<br>
- ЛКМ - Сломать блок.<br>
- ПКМ - Установить блок.<br>
- 0-9 Смена блока.<br>
- ESC - Выйти из мира/игры.

# Особенности
- Генерация игрового мира.<br>
- Типы миров.<br>
- Меню игры.<br>
- Вручную нарисованный текстурпак.<br>
- Свой шейдер.<br>
- Музыка/аудио взяты с открытых источников.<br>
- SkyBox взят с открытых источников.<br>
